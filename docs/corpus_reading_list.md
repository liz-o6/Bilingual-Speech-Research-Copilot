## 使用与限制

在 hw2 目录执行：

```bash
python -m src.rag ingest --catalog data/corpus/catalog.json
```

- 本次只准备语料与 catalog，没有运行付费 API。
- TXT 没有真实 PDF 页码，检索 page=null；正文保留章节标题，但当前 loader 的 section_id 仍为 full-text，不能声称已有章节级 metadata。
- 表格转为按行排列的文字；图像、音频和附加材料未纳入，复杂表头和音标仍需抽查。不要仅依据自动提取内容核实样本量。
- manifest.jsonl 保存作者、DOI、期刊、线上日期、期刊年份、下载地址、hash 与页面版权声明；catalog.json 是当前 ingestion 可读取的精简接口。
- 有些论文线上发表年份与卷期年份不同，manifest 分别保留，后续参考文献使用期刊年份。
- 后续换成 PDF 时，同一篇只保留一个入库格式，更新 catalog 的文件名并保留 doc_id。当前 ingestion 不自动删除旧 TXT，应使用新的 --storage 目录重建，避免旧 TXT 与新 PDF 重复。
- 这些是个人课程研究用的本地副本；PMC 可读不等于全部采用开放再分发许可。公开发布语料包前应逐篇检查 manifest 中的版权说明。

加载与分块干跑验收：15 篇均可由现有 loader 加载，1000/200 配置产生 1709 个 chunks（尚未 embedding/存入 Chroma）。
